## ⚙️ How to Setup Gemini API

With v2.0.5, you can now power up your app using Google's Gemini AI. 

1. Go to your **Profile / Settings** inside Safe Down.
2. Navigate to **AI Settings**.
3. Paste your API Key in the **Gemini API Key** field.
4. Hit **Save** and enjoy personalized AI features 2.0!

> **Don't have a key?** Get one for free from the [Google AI Studio](https://aistudio.google.com/).
